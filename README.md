# Exercício — API do GitHub

Projeto desenvolvido para praticar o consumo da **API REST do GitHub** com Python.

## 📋 Objetivos

O projeto realiza três atividades principais:

### 1. Explorar uma conta do GitHub

- Consultar os dados de um usuário através do endpoint `/users/{username}`.
- Listar os repositórios públicos do usuário.
- Calcular o total de estrelas acumuladas nos repositórios.

### 2. Analisar um projeto open-source

- Selecionar um repositório público e conhecido.
- Consultar a quantidade de estrelas e forks.
- Identificar a quantidade de issues abertas.
- Identificar as linguagens utilizadas no projeto.

### 3. Criar um dataset personalizado

- Coletar informações de múltiplos repositórios.
- Organizar os dados em um arquivo JSON.
- Gerar estatísticas básicas sobre os repositórios analisados.

## 🛠️ Tecnologias

- Python 3
- API REST do GitHub
- JSON
- Requests
